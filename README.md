# Escrow Invoice Operations Dashboard (Power BI)

A Power BI project that tracks the efficiency of an **escrow insurance invoice processing** workflow: how fast invoices are processed, how much investor approvals slow things down, and how many duplicates and resubmissions occur.

> **Data note:** All data in this repo is **synthetic** (randomly generated with a fixed seed). It mimics the *shape* of an invoice-processing workflow but contains no real client, loan, payee or payment information.

**Status:** data model, measures and dashboard plan are ready. The `.pbix` report and screenshots will be added to `/dashboard` once the build is complete.

## Business questions
1. How long does an invoice take from receipt to disbursement, and what share is processed within 3 days?
2. How much longer do investor-coded loans take because of written approvals?
3. What share of invoices is discarded as duplicates or resubmitted?
4. How many invoices are still pending, and how old are they?
5. Which loan types and payee types carry the most value and delay?

## Dataset
`data/escrow_invoices.csv` (150 rows, generated by `scripts/generate_data.py`)

| Column | Description |
| --- | --- |
| invoice_id | Unique invoice reference (INV-00001...) |
| received_date | Date the invoice was received |
| processed_date | Date it was processed (blank if pending) |
| loan_type | Conventional, FHA or VA |
| investor_coded | Y if written investor approval was required |
| payee_type | Servicing Agent or Vendor |
| invoice_amount | Invoice amount |
| approval_days | Days spent waiting for investor approval (0 if not required) |
| processing_days | Total days from receipt to processing (blank if pending) |
| status | Disbursed, Pending, Discarded-Duplicate or Resubmitted |

To regenerate or create a larger file:

```bash
python scripts/generate_data.py --rows 1000 --out data/escrow_invoices.csv
```

## How to build the report
1. Power BI Desktop: **Get data > Text/CSV** > load `data/escrow_invoices.csv`. Name the table `invoices`.
2. In Power Query set types: dates for `received_date` and `processed_date`, decimal for `invoice_amount`, whole number for `approval_days` and `processing_days`.
3. Add a date table (Modeling > New table):
   ```DAX
   Calendar = CALENDAR(MIN(invoices[received_date]), MAX(invoices[received_date]))
   ```
   Relate `Calendar[Date]` to `invoices[received_date]`.
4. Create the measures below, then build the pages in the plan.

## DAX measures
```DAX
Total Invoices = COUNTROWS(invoices)

Disbursed Invoices = CALCULATE([Total Invoices], invoices[status] = "Disbursed")

Disbursed Amount = CALCULATE(SUM(invoices[invoice_amount]), invoices[status] = "Disbursed")

Pending Invoices = CALCULATE([Total Invoices], invoices[status] = "Pending")

Avg Processing Days = AVERAGE(invoices[processing_days])

Avg Processing Days (Investor Coded) =
CALCULATE(AVERAGE(invoices[processing_days]), invoices[investor_coded] = "Y")

Avg Processing Days (Not Investor Coded) =
CALCULATE(AVERAGE(invoices[processing_days]), invoices[investor_coded] = "N")

Processed Within 3 Days % =
DIVIDE(
    CALCULATE([Total Invoices], invoices[processing_days] <= 3),
    CALCULATE([Total Invoices], NOT ISBLANK(invoices[processing_days]))
)

Duplicate Rate % =
DIVIDE(CALCULATE([Total Invoices], invoices[status] = "Discarded-Duplicate"), [Total Invoices])

Resubmission Rate % =
DIVIDE(CALCULATE([Total Invoices], invoices[status] = "Resubmitted"), [Total Invoices])

Avg Pending Age (Days) =
AVERAGEX(
    FILTER(invoices, invoices[status] = "Pending"),
    DATEDIFF(invoices[received_date], TODAY(), DAY)
)
```

## Dashboard plan
**Page 1 - Overview:** KPI cards (Total Invoices, Disbursed Amount, Avg Processing Days, Processed Within 3 Days %, Pending Invoices), monthly invoice trend line, status donut, slicers for loan type and payee type.

**Page 2 - Turnaround & approvals:** clustered column of Avg Processing Days for investor-coded vs not, distribution of processing days, table of the slowest invoices.

**Page 3 - Quality & exceptions:** Duplicate Rate %, Resubmission Rate %, exceptions by loan type, pending invoices with their age.
